# v0.6：带证据的持续经验学习

日期：2026-10-10。执行依据：用户已要求继续研究、落实早期后续工程，测试、PR、审查后合并。沿用已批准 v0.4 的无人日常闭环，不新增逐阶段人工审批。

## 意图与取舍

长期目标是 Hermes 自行发现工作、完成工作、从可信反馈改变后续策略。本轮填补 v0.4 的经验学习缺口：现在执行请求没有经验，失败提示只有固定文字。采用私有账本中的数据型策略，而非重写宿主或让任务执行器修改控制内核。原生可执行技能的自动发布需要独立隔离评测器；当前 v0.5 禁用 host argv 验证，因此不能用它冒充技能代码已验证。

三个路径：仅把失败句子加进提示成本低但无法判断失效；完整自动改内核需新的可信构建/测试/发布边界；本轮选择有来源、范围和状态的策略记忆，可完整实现自动学习、试用、晋升和退役。

## 行为契约

1. 只有已静止 submission 的机械失败证据可触发经验生成。未知、受阻、取消、已有产物、模型自述不生成学习真值。来源为 submission ID、冻结验收 hash、失败 artifact hash/原因及简短目标，不保存全文轨迹或源资料。
2. 使用原生 `ctx.llm`、用户配置的 DeepSeek Flash 和共享辅助预算；每 tick 至多一次经验模型调用，每失败 submission 最多两次实际生成尝试。预算不可用不消耗生成尝试；崩溃后的已保留调用不退款。120 秒租约与代次防止两个进程接受同一候选，45 秒模型超时；晚到响应不能覆盖新 owner。暂停/停止禁止新学习调用。
3. 模型只输出最多 600 字符的 `guidance`。候选 scope 由控制器确定：source ID、domain、完整 contract hash、执行身份、学习 schema 版本。模型不能生成权限、可执行代码入口或验收。相同失败只创建一个不可变候选。
4. 后续相同 scope 的任务可取最多两条候选/活动策略，活动优先。请求携带 ID、正文 hash、正文及明确的 hypothesis 状态，随 submission 原子冻结。故障重放使用原始请求，不检索新策略。退役策略不进入新请求，旧在途请求仍能恢复。
5. 机械评估只消费冻结请求中实际选用的策略及相符 hash。原失败的重试成功只算修复原例；两项不同、晚于候选生成、不是原目标且首次尝试成功的目标才将候选提升为 active。后续任务在生成时未向经验模型展示，是在线留出评估；这是使用关联证据，不证明因果改善或通用迁移。每次评估有唯一 submission/strategy 键；重复 tick/重启不加样本。
6. 任何可靠的已静止失败复用使候选或活动策略 retired；相关未知结果不晋升也不制造失败。退役不可被旧成功复活；检索可退回先前仍有效策略，若没有则正常无经验执行。经验不能覆盖验收，也不计为额外能力成功。
7. 自我模型与公开只读界面报告候选、活动、退役、证据和有限适用范围。LLMPlanner 得到对应执行身份的经验、能力上下文与当前承诺；执行器实际得到具体策略。新模块受原 v0.5 控制文件保护，worker 无法写策略账本。
8. 兼容旧数据库、四工具/一命令/十一 hooks、默认禁用 autonomy、标准库、Python 3.11/3.12/3.14、固定宿主 `73162b00eefde3794bed0afb53d84a19c0eed230`。经验子系统故障不得取消未知执行对账或旧观测接口。

## 组件

`experience_store.py` 使用 Ledger 的 SQLite 事务保存学习 job、不可变策略和去重评估；`experience.py` 负责受预算/生命周期约束的结构化候选生成。Controller 在恢复后、新工作前评估/生成，派发时冻结检索结果。SelfModel 导出经验状态，旧统计语义不变。安装、原生部署复制新文件，模型工具不增加写入经验接口。

## 验证

实际 SQLite/Controller 场景验证：一份已核验失败产生候选；下一任务请求随经验不同而改变，关闭经验的对照没有该字段；两项独立首次成功晋升；失败自动退役；未知/旧产物/原例重试不晋升；跨来源/验收/身份不迁移；并发认领、崩溃重启、过期响应、预算恢复、停止以及同键重放。完整旧套件和原生宿主 smoke 必须通过；另用真实 ctx.llm 做有限 DeepSeek 候选生成并记录模型与预算。不得把 mock 结果报告为真实工具能力。

## 长期工程顺序

本轮：证据学习与数据策略生命周期。下一阶段：独立工作区中的可执行技能候选、可信回归/留出评测和版本发布/自动回滚。其后：持久分步计划与前提失效重规划、只读外部输入根与连接器、真实事务回执/幂等恢复、跨领域基准和长时故障实验。自动内核发布最后依赖独立构建与验证控制面。主观意识仍无本工程可证明的验收。
