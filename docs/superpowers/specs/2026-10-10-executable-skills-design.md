# 可执行技能工程 v0.7

用户已授权持续研究、落实、测试、独立审查、提交 PR 并合并。目标是在现有自主闭环中积累能执行的程序，减少重复解决同一类问题的开销。本版工程能力不构成主观意识或通用智能的证明。

## 选择与边界

选择私有账本保存内容不可变的 Python 程序，将通过独立评测的单个程序及 SHA-256 随执行请求冻结。原生 Hermes 收到 JSON 文本后可在已有隔离 terminal 中复制并调用程序。原生 skills 保持空的只读挂载，宿主机从不 import、exec 或运行候选程序。相比可变 skills 目录，这避免更新目录与旧请求重放之间的版本漂移；新增专用工具和动态挂载留给后续独立工程。

`autonomy.executable_skills` 是控制面可信配置，默认空列表；最多 4 项。每项包含 `id`、`source_id`、`contract_id`、`description`、`image`、`examples`、`holdout`。例子为 `{input, output}`，至少 1 个公开回归例和 2 个未公开例，总数最多 8；每个 JSON 输入/输出最多 4096 UTF-8 字节，拒绝非有限数。镜像必须是 SHA-256 digest 固定的本地镜像。受保护部署要求评测镜像与 worker 镜像相同。测试清单随受保护配置冻结，程序没有权限修改。

## 学习、评测与发布

只从已有账本中已静止、非取消、机械验收为 false、契约 hash 匹配的提交生成任务。范围包括源、领域、完整契约 hash、执行身份和完整测试清单 digest；身份或测试版本变化不迁移技能。合成器仅看到任务描述、公开例和最小失败凭据，不看到 holdout 输入或答案，也不读取完整聊天、轨迹或原始事实。代码最多 6000 UTF-8 字节，JSON stdin → 单个 JSON stdout，只允许依赖镜像内 Python 标准库。共享现有辅助模型原子预算；每个失败/技能组合最多 2 次模型调用，45 秒，失败冷却 60 秒。禁用 learning、暂停或 stop 阻止新合成和评测，但静止提交的退役结算仍执行。

每个测试在一个新 Docker 容器执行，仅挂载临时程序目录只读；stdin 只有当前测试输入，完整清单和期待输出留在宿主控制面。宿主严格解析 stdout 并比较规范 JSON，退出码 0 不是通过证据。固定本地 socket，pull never，network none，UID/GID 1000，read-only root，cap-drop ALL，no-new-privileges，1 CPU、128 MiB 内存及 swap、16 PID，8 MiB noexec tmpfs。候选运行最多 2 秒、stdout/stderr 合计最多 16384 字节；Docker 控制操作各有独立有界超时。任何错误、超限、输出不符都不能发布；Docker 清理无法确认则保留 unknown，阻止后续评测。

launch 前持久化评测 token；整个清理、认领、生成、评测、结算在同一跨进程 flock 下。Docker 客户端继承锁 FD，父进程崩溃后不能在另一进程清理完再迟到创建容器。持锁入口先清理本账本标签的残留容器并确认消失；过期 lease 的已冻结代码重测，不再付费生成。owner/generation/lease 拒绝迟到结果。容器名按持久 token 和测试序号生成，报告只记录输入/输出 hash、通过数、清理确认和镜像身份，不暴露未公开答案。

所有公开和未公开例都通过且确认容器清理后，事务内发布版本。单一范围最多一个 active，前一有效版本 standby。候选内容、范围、来源、token 不可改写；评测报告一旦结算不可改写。退役版本永不复活。新请求的绑定在准备提交的同一 SQLite 写事务内检查当前 active 内容/hash/范围/测试版本；旧请求重放使用原冻结内容，即便该版本已退役。

## 真实复用与回退

仅匹配冻结绑定、来源、身份、契约的静止机械结果才结算一次复用记录。false 保守退役所绑定版本；若它仍是 active，选择同范围最近一个未退役、通过评测的 standby；没有备用时禁用该范围的技能。较旧请求的失败不得退役更新版本。true 记录有限关联，不声称因果收益、程序确实被调用或通用正确性。

本版评测公开回归例和未公开例，**不把它们称作任意原失败的精确回放**：旧账本未冻结失败时的业务输入。以后加入不可变输入快照才能做精确回放。日常请求绑定也不证明实际执行程序；原生 smoke 额外检查实际 terminal 调用、脚本 hash 和机械产物。

## 验证与后续

测试覆盖伪造输出、自报通过、隐藏清单泄漏、代码/测试漂移、stale lease、预算、暂停、并发认领、崩溃残留、清理未知、active/standby/retired 回退、旧绑定事务拒绝和重放稳定。实际 Docker 验证正确/错误/超时/越界候选；实际固定原生 Hermes + DeepSeek Flash 完成一次有限生成、评测、复用，明确标注合成失败夹具，不伪称 provider 故障。完整 Python 3.11/3.12/3.14 CI 和独立全分支审查后合并。
