# 从残留工程到 v0.6 证据学习

日期：2026-10-10。审计基线：v0.5 main `8b7116c8dc504aa6dffa3bcc3e20ddf98603d25a`。两条独立只读研究线核对 v0.4 原始设计、正文研究及当前实现，重读本地原作者全文相关方法与失败分析；没有重跑论文实验，也未把论文数值当成本产品能力。

## 实际缺口

`SelfModel` 已有机械结果、校准和版本，但失败假设只是固定句子；`LLMPlanner` 未传上下文/承诺，执行请求完全不含经验。v0.5 已补常驻监督，但早期提出的经验检索、候选验证与自动回退仍没有状态机。因此本轮实现数据型策略闭环，留下可执行技能评测作为有清晰依赖的下一阶段。

## 文献证据与工程决定

| 依据 | 本轮核对的具体内容 | 对实现的影响与局限 |
|---|---|---|
| [Reflexion v4](https://arxiv.org/pdf/2303.11366v4)，§3、§4.1/4.3、§5 | 反思送入后续 Actor；自生成测试有 false positive/negative，某些反思消融会退化 | 经验必须进入实际请求；使用原机械验收，不以反思文本自证有效。两项在线独立任务门槛是工程选择，论文不保证它足够 |
| [Generative Agents v2](https://arxiv.org/pdf/2304.03442v2)，retrieval/reflection、失败分析 | 检索按相关性等排序，反思保留记忆引用；不完整检索仍产生无依据扩写 | 保留 submission/evidence/hash 来源；缩小范围，未知不生成能力事实。行为可信度评价不能代替业务完成 |
| [Voyager v2](https://arxiv.org/pdf/2305.16291v2)，§2.1–2.3 | 当前状态/已成败目标决定课程，成功程序进入技能库，多轮失败可换任务 | 支持复用与失效控制。Minecraft 的模型自验证程序库不能直接移植到受控 Hermes 作为可信代码发布 |
| [Fleming & Daw 2017](https://doi.org/10.1037/rev0000045)，已有作者稿全文研究 | 区分能力、校准及识别错误的 sensitivity | 报告范围、分母、首次/最终结果；监控须影响下一行动。不能从自述推断意识 |
| [Butlin 等 v3](https://arxiv.org/pdf/2308.08708v3)，已有指标/限制研究 | 功能指标用于研究，不等同于意识证明 | 把可检验的经验、承诺、修正和恢复落实为工程，不宣称主观意识 |

进一步原文范围、认知/心理学/可靠性工程背景见 [v0.4 正文研究](2026-10-09-cross-disciplinary-autonomy.md)。本轮使用现存原作者资料和代码审计，没有伪称发现 2026 新论文。

## 已实现机制及可证范围

可信失败→有界候选→未来同范围请求试用→两项新目标首次成功激活→实际失败退役。学习和评估使用私有账本，冻结请求提供使用来源；请求重放不重新检索。经验故障隔离于执行对账，辅助生成与规划共享原子预算。候选不会写进原生 skills，也不能执行控制代码。

在线留出目标在候选生成后创建，学习模型没有得到未来目标/结果。样本证明策略被使用时该契约成功；没有随机配对预算/任务实验，不声明改善由策略造成。场景测试中比较带经验与关闭经验的请求，证明控制路径有行为差别；它也不等于性能提升。

## 长期工程路线与验收

| 顺序 | 依赖与交付 | 完成证据 |
|---|---|---|
| 本轮 v0.6 | 受控 runtime + 可信 receipt；数据策略学习/试用/激活/退役 | 并发/重启/预算/范围/重复结算测试及有限真实 DeepSeek/原生使用 |
| 下阶段可执行技能 | 独立只写 candidate 工作区；可信测试清单/版本；原失败回放与未展示留出任务；不允许 candidate 改评测控制面 | 错实现拒绝、回归拒绝、依赖漂移拒绝；通过后版本发布，新任务复用，可靠回归自动回滚 |
| 持久分步计划 | 冻结目标验收；步骤依赖/前提版本；新事实失效规则、循环检测 | 重启保留计划，新前提改变后实际重规划，不能削弱验收 |
| 外部输入/真实事务 | 独立只读输入根与连接器，收据绑定、服务能力/幂等及未知对账 | 输入原子更新不扰动控制；实际邮箱/日历服务的有限授权事务恢复测试 |
| 长时与内核发布 | 磁盘额度、真实守护部署、提供商故障与运行成本观测；独立构建/测试/发布监督器 | 真实 soak 时长/失败率，版本晋升和失败回滚，未决执行不能靠部署重置消失 |

本轮不把长期路线文件当作这些工程已完成；对应真实部署/凭据与独立评测基础建立后，按此顺序继续。
