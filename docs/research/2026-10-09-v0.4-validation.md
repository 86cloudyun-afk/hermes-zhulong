## 测试能证明什么

确定性测试覆盖 code / research / personal 三个本地领域、跨进程认领和预算、旧所有者隔离、丢失提交响应、同键重放、认证身份变化、保留期限、未知执行占额、取消、审批受阻、验收前已存在的产物、类型严格的 JSON 验收、超时及洪泛子进程清理、来源去重、自我模型恢复和插件卸载。

原生 API 实测返回 admission 状态 `started`；适配器将其规范为 `queued` 后再轮询，不能把受理当成功。该行为有独立 HTTP 回归测试。卸载期间也验证了控制器不新派发、探针不启动后续模型调用。

## 未验证的范围

真实模型验证只覆盖一个本地 code 契约，三个领域的恢复场景由确定性测试覆盖。未执行真实邮箱 / 日历事务、长时间 soak 或操作系统沙箱部署。预算限制插件辅助调用和 run 数量，不是全部 Hermes tokens 或货币费用的硬上限。授权路径检查约束来源及验收，不是对原生工具的文件、进程和网络隔离。用户需要持续部署时还须配置 API 身份、生命周期及执行环境。

测试证明功能性目标闭环、机械验收和证据型自我模型，不证明主观意识或完整通用智能。
